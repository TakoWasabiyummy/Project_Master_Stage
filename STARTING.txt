前置条件：已安装 Python 3.10+（https://www.python.org/downloads/）
          安装时勾选 "Add Python to PATH"

-------------------------------------------------------------------------------
步骤 1：打开 PowerShell，进入项目目录
-------------------------------------------------------------------------------
  cd C:\Users\Administrator\IDEProjects\ULM_APP

-------------------------------------------------------------------------------
步骤 2：创建 Python 虚拟环境
-------------------------------------------------------------------------------
  python -m venv .venv

-------------------------------------------------------------------------------
步骤 3：激活虚拟环境
-------------------------------------------------------------------------------
  .\.venv\Scripts\Activate.ps1

  注意：若 PowerShell 提示执行策略错误，先运行以下命令（仅需一次）：
    Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

-------------------------------------------------------------------------------
步骤 4：升级 pip 并安装依赖
-------------------------------------------------------------------------------
  python -m pip install --upgrade pip
  pip install -r requirements.txt

  若需接入医院 PACS 系统（DICOM 影像），追加安装可选依赖：
    pip install pydicom

-------------------------------------------------------------------------------
步骤 5：启动应用
-------------------------------------------------------------------------------
  streamlit run uploadingfigure.py

-------------------------------------------------------------------------------
步骤 6：访问应用
-------------------------------------------------------------------------------
  启动后终端将显示：
    Local URL: http://localhost:8501

  浏览器会自动打开；若未自动打开，手动访问上述地址即可。

===============================================================================

===============================================================================
常见问题
===============================================================================

Q: 启动后页面中文显示为方框？
A: 系统缺少中文字体。Windows 通常自带 Microsoft YaHei，若仍异常，
   将任意中文字体文件（如 msyh.ttc）复制到项目根目录即可。

Q: 上传 .dcm 文件报错 "DICOM 支持未启用"？
A: 未安装 pydicom。运行：pip install pydicom，然后重启应用。

Q: 端口 8501 被占用？
A: 指定其他端口启动：streamlit run uploadingfigure.py --server.port 8502

Q: 部署到华为云 Linux 服务器？
A: 将 Activate.ps1 替换为 source .venv/bin/activate，其余步骤相同。
   确保安装中文字体：sudo apt install fonts-noto-cjk（Ubuntu/Debian）
                     sudo yum install google-noto-sans-cjk-fonts（EulerOS/CentOS）
