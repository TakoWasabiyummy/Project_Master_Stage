===============================================================================
  乳腺癌影像组学预测平台 — 环境配置说明
  技术提供：华为云码道 (CodeArts) · 规范驱动开发 (SDD)
===============================================================================

一、Python 版本
-------------------------------------------------------------------------------
  Python >= 3.10
  说明：代码使用 PEP 604 类型标注语法（tuple[...], dict[str, float]）及
        typing.Optional，需 Python 3.10 及以上版本运行。

二、必需依赖包
-------------------------------------------------------------------------------
  包名            最低版本    用途
  --------------- ---------- -----------------------------------------------
  streamlit       >= 1.32    Web 应用框架，提供交互式影像上传与推理界面
  Pillow          >= 10.0    图像 I/O 与处理（加载、格式转换、绘制 ROI 标注）
  numpy           >= 1.24    数值计算（矩阵运算、统计量、掩膜运算）
  matplotlib      >= 3.7    可视化绘图（SHAP 特征贡献度、多模型对比条形图）

三、可选依赖包
-------------------------------------------------------------------------------
  包名            最低版本    用途
  --------------- ---------- -----------------------------------------------
  pydicom         >= 2.4     DICOM 医学影像格式读取（PACS 系统接入必需）

  说明：pydicom 未安装时应用仍可正常运行，但 file_uploader 将不接受
        .dcm 文件上传。若需接入医院 PACS 系统，请务必安装：
          pip install pydicom

四、系统字体要求
-------------------------------------------------------------------------------
  1. matplotlib 中文渲染：需安装以下任一中文字体
       Windows  : Microsoft YaHei / SimHei / SimSun（系统自带）
       Linux    : Noto Sans CJK SC / WenQuanYi Micro Hei
       macOS    : PingFang SC / Heiti SC

  2. PIL ROI 文字标注：需安装以下任一字体
       Windows  : Arial（系统自带）
       Linux    : DejaVu Sans / Liberation Sans（matplotlib 自带）
       macOS    : Helvetica

  说明：字体缺失时应用不会崩溃，会自动降级为默认字体，但中文/标注
        可能显示为方框。跨平台部署时建议将字体文件打包至项目根目录。

五、操作系统与硬件
-------------------------------------------------------------------------------
  操作系统：Windows 10/11、Ubuntu 20.04+、EulerOS、macOS 12+
  硬件  ：最低 4 GB 内存 / 2 核 CPU（纯 CPU 推理，无需 GPU）
  磁盘  ：依赖安装约需 500 MB 可用空间

六、网络与端口
-------------------------------------------------------------------------------
  默认端口：8501（Streamlit 默认）
  网络要求：本地运行无需外网；首次安装依赖需访问 PyPI 镜像源
  PACS 集成：若接入医院 PACS，需开放 PACS 服务端口（通常 104 / DICOM）

七、一键安装命令
-------------------------------------------------------------------------------
  pip install streamlit>=1.32 Pillow>=10.0 numpy>=1.24 matplotlib>=3.7 pydicom>=2.4
